DIORAMA SWITCH / 微缩景观开关

一间房，一枚开关

八间 1:12 的等距微缩房间，八种光的性格。拖动那枚玻璃球：球走到哪里，光就跟到哪里 —— 白天它替房间向城市借光，入夜只剩一盏灯。每一个都是独立组件。

3 200LX 06:40 · 窗朝东
八间房 / 各自一个组件
用法
<!-- 引入一次，注册元素；八间房随包注册 -->
<script type="module" src="./src/diorama-switch.js"></script>

<!-- 用哪一间，写哪个 room -->
<diorama-switch room="cyber" height="260"></diorama-switch>

<!-- 只要一间房：只 import 那一个文件 -->
<script type="module">
  import "./src/rooms/garden.js";
  import "./src/diorama-switch.js";
</script>

属性：room 房间 id · height 高度 px（宽度按 1.82:1 自动算）· value 0–1 昼夜进度。方法：toggle() / animateTo(v, ms)。事件：diorama-change。无障碍：role="switch" + aria-checked，键盘 Space / Enter / ← / →。
